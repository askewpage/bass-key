# Bass Clef Trainer

Статический сайт-тренажер басового ключа для GitHub Pages.

## Возможности

- Клавиатура на 5 октав (`C2` - `B6`)
- Случайная нота в басовом ключе
- Нота рисуется программно через SVG (без картинок из интернета)
- Добавочные линии: до 2 снизу и до 2 сверху
- Звук клавиш: piano-сэмплы через Tone.js
- Проверка ответа: правильно/неправильно
- Статистика попыток и точности

## Архитектура

- `index.html` - разметка страницы
- `js/main.js` - точка входа
- `js/game.js` - игровой контроллер
- `js/keyboard.js` - генерация клавиатуры
- `js/music.js` - музыкальная логика и диапазоны
- `js/staffRenderer.js` - отрисовка ноты и стана (SVG)
- `js/constants.js` - константы
- `styles/main.css` - сборка стилей
- `styles/variables.css` - CSS-переменные
- `styles/base.css` - базовые стили
- `styles/layout.css` - лейаут
- `styles/components.css` - компоненты

## Публикация на GitHub Pages

1. Создай репозиторий и добавь все файлы проекта.
2. Запушь в ветку `main`.
3. Открой `Settings` -> `Pages`.
4. В `Build and deployment` выбери:
   - `Source`: `Deploy from a branch`
   - `Branch`: `main` и `/ (root)`
5. Сохрани. Через 1-2 минуты сайт появится по ссылке Pages.
